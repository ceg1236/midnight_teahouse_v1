# Modal Content

Edit these files to change what appears in the modals. No code changes needed.

## title-modal.md

The "midnight teahouse" modal. Use section headers to control font styling:

- **# Greeting** — Playwrite font (e.g. "Hi friend,")
- **# Question** — Playwrite font (e.g. "What is the Midnight Teahouse?")
- **# Body** — Vend Sans font (paragraphs of content)
- **# SignOff** — Playwrite font (e.g. "Thanks for visiting us...")

Just edit the text under each header. Blank lines between paragraphs are fine.

## modals/

One file per icon: `tea.md`, `candle.md`, `kora.md`, `table.md`. Plain text — whatever you write appears in that modal's body (Vend Sans font).
